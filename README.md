# Stroy — гитарный тюнер

Тюнер для гитары в браузере: альтернативные строи (Drop D, D Standard, Open G, 7-струнные и свои), 
стрелка и строб, проверка мензуры по 12-му ладу, точный эталонный звук, 15 языков. 
Создатель — **xnyokki**. 
Устанавливается на телефон как приложение и работает без интернета.

**Открыть:** https://xnyokki.github.io/stroy/

## Как установить на телефон
- **Android (Chrome):** меню ⋮ → «Установить приложение».
- **iPhone (Safari):** «Поделиться» → «На экран Домой».

## Файлы
- `index.html` — всё приложение
- `manifest.webmanifest` — данные для установки
- `sw.js` — офлайн-режим
- `icons/` — иконки
